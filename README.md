# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

新写入必须填入库货位码，格式由炮制员在「入库货位」页设定：汉字仓名 + 斜线 + 固定位数货架号（默认 甲仓/两位，如 甲仓/01），不符则拒写；规则变更仅约束后续提交。每次写入与改正都记入货位流水，改正只追加新流水，早先流水不改写。质检员可查阅规则与流水，不可改规则。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 顶栏进「入库货位」，再写一条温度 200 的清炒（货位码填 甲仓/01），结论仍是未放行。
3. 货位码填 甲仓01（缺斜线）被拒写；不填货位码也拒写。
4. 在「货位改正」把该行改为 甲仓/02，货位流水新增一条「改正」，早先那条「写入」流水不变。
5. checker 看不到写入按钮；能查规则与流水，但看不到规则编辑，改规则接口返回 403。
