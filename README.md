# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

入库货位码强制：新写必须填货位码，格式为「炮制员设定的汉字仓名 + `/` + 两位货架号」（如 `甲仓/01`），不符拒写。仓名规则由炮制员在「入库货位」页设定，变更后仅约束后续提交。货位码写入只追加的货位流水；事后改正某行货位码只新增一条「改正」流水，早先的「写入」那条不被改写。质检员可查阅规则与流水，不可改规则。顶栏「入库货位」落地页含规则设置、写入时货位栏、货位流水。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 入库货位：规则为「甲仓/两位」时，填 `甲仓/01` 成功，缺斜线的 `甲仓01` 被拒（422）。
5. 规则改成乙仓后，仅之后的提交按乙仓校验；改正某行货位码，流水里早先的「写入」条不变，只新增「改正」条。
6. checker 能看规则与流水，但改规则、改正货位均被拒（403）。
